# Elizabethan Worldview

Starter Next.js app for **elizabethanworldview.com**.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build and quality checks

```bash
npm run lint
npm run build
```

## Deploy to Vercel

1. Push this repo to GitHub/GitLab/Bitbucket.
2. Import the repo in Vercel.
3. Framework preset: **Next.js** (auto-detected).
4. Deploy.
5. Add custom domain `elizabethanworldview.com` in Vercel project settings.
